# RESOURCES.md Format

Curated trusted sources for the topic. Knowledge should be drawn from here, not parametric guesses.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _Title_ — Author](https://example.com)
  Foundational text. Use for: ...

## Wisdom (Communities)

- [r/example](https://reddit.com/r/example)
  High-signal community. Use for: ...
- Local: {class or meetup}
  Use for: real-time feedback.
```

## Rules

- **High-trust only.** Primary sources, recognised experts, peer-reviewed work, well-moderated communities.
- **Annotate every entry.** One line: what it covers and when to reach for it.
- **Group by Knowledge / Wisdom.**
- **Surface gaps explicitly.** If no good resource exists for a mission area, list it under `## Gaps`.
- **Prune ruthlessly.** Remove sources that turn out wrong, shallow, or off-mission.
- **Record community preferences.** If the user opts out of communities, note it.
